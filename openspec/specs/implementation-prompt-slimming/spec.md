## ADDED Requirements

### Requirement: Implementation prompt MUST emit a compact phase contract
The implementation prompt generated by `ai/scripts/ai_implementation.sh` MUST include a concise contract that states implementation-phase execution checklist source, verification timing, and handoff boundary.

#### Scenario: Compact contract is present
- **WHEN** implementation prompt content is generated for a step
- **THEN** it includes a short contract covering checklist source, verification timing, and implementation handoff boundary

#### Scenario: Contract remains phase-scoped
- **WHEN** implementation prompt content is generated
- **THEN** it avoids re-emitting long multi-paragraph process blocks that belong to global process documentation

### Requirement: Implementation prompt MUST reference authoritative process rules
Implementation prompt output MUST reference `ai/AI_DEVELOPMENT_PROCESS.md` as the authoritative source for detailed implementation-phase workflow and gates.

#### Scenario: Authoritative source is explicit
- **WHEN** implementation prompt content is generated
- **THEN** it explicitly points to relevant sections of `ai/AI_DEVELOPMENT_PROCESS.md` for detailed rules

#### Scenario: Rule de-duplication is preserved
- **WHEN** implementation prompt strings are updated
- **THEN** detailed process text remains centralized in `ai/AI_DEVELOPMENT_PROCESS.md` rather than duplicated in script prompt output

### Requirement: Context pack MUST keep step-specific implementation inputs
Implementation prompt context MUST retain step-specific execution inputs required for correct implementation work, including ordered plan bullets, constraints, tests/risks, and linked requirement excerpts.

#### Scenario: Required step context remains available
- **WHEN** implementation prompt content is generated after slimming
- **THEN** it still includes ordered bullets, key constraints, tests/risks, and linked requirements excerpts needed for execution

#### Scenario: Redundant summaries are removed
- **WHEN** implementation prompt content is generated
- **THEN** redundant process-summary content that duplicates global process rules is omitted from the context pack

### Requirement: Prompt-focused tests MUST guard compactness and behavior
Test suites under `tests/ai_scripts/` MUST verify compact-contract presence, absence of removed duplicated text blocks, and measurable prompt size reduction for equivalent step artifacts.

#### Scenario: Compact contract assertions pass
- **WHEN** prompt-focused script tests run
- **THEN** tests assert required compact-contract markers and authoritative process references

#### Scenario: Size regression is detected
- **WHEN** implementation prompt output grows beyond defined compactness expectation for equivalent fixtures
- **THEN** prompt-focused tests fail with clear guidance that de-dup/sizing contract regressed
